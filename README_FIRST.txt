MathArcade:Multiplication Quest! (MMQ!) Game Kit
GitHub Pages Ready Version

This version is prepared for online hosting through GitHub Pages.

WHAT WAS PREPARED
1. START_HERE.html was copied as index.html because GitHub Pages needs index.html at the top level.
2. A .nojekyll file was added so GitHub Pages serves the HTML/CSS/JS files directly.
3. The introduction song/video was compressed to below 25 MB so it can be uploaded using the GitHub website.
4. The existing games folder structure was kept.

HOW TO UPLOAD
1. Extract this ZIP file.
2. Open the extracted folder named MathArcade_GitHub_Pages_Ready.
3. Upload everything INSIDE this folder to your GitHub repository root:
   - index.html
   - START_HERE.html
   - START_HERE_EN_GB.html
   - START_HERE_ZH_CN.html
   - games folder
   - media folder
   - .nojekyll
   - README.md
4. Do not upload only the ZIP file.
5. In GitHub, go to Settings > Pages.
6. Select Deploy from a branch.
7. Select main and /(root), then Save.

EXPECTED WEBSITE LINK
https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/
