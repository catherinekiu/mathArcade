# MathArcade: Multiplication Quest! (MMQ!) Game Kit

This folder is prepared for GitHub Pages.

## Important

- Upload the CONTENTS of this folder to the root of your GitHub repository.
- Keep `index.html` at the top level of the repository.
- Keep the `games/` and `media/` folders beside `index.html`.
- Do not upload only the ZIP file, because GitHub Pages will not automatically extract it for the website.

## Recommended GitHub Pages settings

1. Create a new GitHub repository.
2. Upload all files and folders from this folder.
3. Go to Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch: main.
6. Choose folder: /(root).
7. Save.

Your page will normally be available at:

https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/
